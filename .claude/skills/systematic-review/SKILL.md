# 系统综述检索

负责 PubMed 检索与可追溯材料，不代替研究者批准、正式纳排或全文核查。日常任务转 [literature-search](../literature-search/SKILL.md)，日常结果不视为已批准方案。

## 按阶段读取

只读当前阶段所需章节，不预读整套文档；本轮已核对且未变化的内容不重读。

| 阶段／任务 | 读取目标 |
|---|---|
| 拟策略、查词、已知集诊断、方法复核 | [操作导航](references/operations.md) → `systematic-review-workflow.md` 对应章节。 |
| 改式、设计筛选、分页、缺题录、摘要或重复回传 | [检索](../literature-search/references/retrieval.md)对应章节。 |
| 单独导出、补检、追引、差集、题录续跑 | 操作导航 → `retrieval-files.md`；追引要整页标题时，首次 `links` 就传 `with_titles=True, compact=True`，超过检查预算则分页。不强制建综述方案。 |
| 交付、恢复或核验完成 | 操作导航 → `review-delivery.md`；写方案才读 `review-plan.template.json`。 |
| 审计报告／缺口 | 操作导航 → `audit-report.md`；执行 CLI 才查安装记录与命令前缀。 |
| 解读或比较研究结论 | [选读与比较](../literature-search/references/reading.md)；不能仅凭类型标签判断质量。 |

## 策略与执行

- 明确问题与预设纳排，按问题选 PICO／PECO／诊断框架／PCC，非全部要素都进检索式。缺信息可拟草案并标待确认；演练不冒充用户研究，首屏人群分布不改变问题范围。
- 尽可能用多来源、独立于当前检索的已知集并记出处；缺少可试检，标“未完成独立已知集验证”，不能倒用本次命中造金标准。找回仅证明该集合匹配，不代表整体查全／查准率。
- 用核心概念，核实 MeSH 范围、层级、历史词并复用；适用时结合标题摘要同义词，含英美拼写与缩写展开；缩写按摘要定义，不凭共现纳入。概念内 OR、间 AND，引号只包短语。设计纳排不等于可靠过滤器；筛选须有适配依据并核对遗漏，不只靠设计字词／类型标引。
- 题录直接 `search`，仅计数用 `count`；初看 `brief`、引用 `full`、名单 `ids`。先读切题摘要再按缺口改式。普通分页用 `retmax`；`max_show`／`previous_path` 须配 `out_path`。日期 `pdat`／`edat` 含首尾；同字段重复不扩不缩，跨口径或不等价叠加取交集。展示去重不等于筛选，页快照不替代全量导出，关键策略变化检查完整增减。
- 每次检查实际式、警告及返回的 `term_ignored`、`term_degraded`、各批 `querytranslations`；`term_ignored`／`term_degraded` 按批判定，不连带作废其他批的 `found`。已知集的 `retrieved` 是实取，`found` 才是核实找回。`unknown` 不计漏检，按 `checks` 查对应批次；失真须修复，不能以已有候选代替有效集合。零命中复核，失败不当零命中。披露日期、排序、查看范围与未取全状态；排名／差集前列非随机样本。
- 保留完整基线、查询及改式理由、时点、警告和审计状态；补检／新增不替代基线。`diff` 的 `provenance.comparison=needs_review` 表示仅观察到实取名单差异，不能认定改式新增；`removed` 不等于数据库删除。导出核对计数、去重和缺失，哈希只证一致性；导出绑定最终式、字段与日期窗口，按固定名单逐号核验，同条数不证明同集合。缺独立已知集保持草案／`needs_methodology_review`，不以本轮命中充验证集。单库非全部检索，外部数据库与追引的范围决策、实际执行分开记。

## 证据边界

人工阅读或初筛摘要默认用 `fetch_abstracts(pmids=..., fields="title,abstract")` 直接读精简文本；按 PMID 区分已读摘要、仅有其他摘要、记录无摘要和未取回记录。仅有其他摘要时按需取 `fields="title,other_abstracts"`，不能标成无摘要。需要作者单位或 NCBI 原排版时省略 `fields`；批量交付仍按方案导出。

试检只写题录事实、线索用途和待判事项。比如来信、回复或无摘要记录：可沿题名或关联定位原研究；未读全文不能断言「无原始数据」。纳排标准未批准或证据不足，统一记「待判」，不写「应排除／不入证据表」；找到原研究也不等于纳入。

缺题录按 `missing_pmids` 补取、留原名单；缺摘要不自动排除。裁剪字段仍查 `warnings`、`missing`、`no_abstract`、`abstract_requested`；未请求不等于无摘要。撤稿、关注声明、勘误核对关联，未见标记不证明无问题。

区分题名初筛／摘要／全文，摘要不足标 ⚠️【待确认】，不替代完整偏倚评价；研究系列、综述及其纳入研究不重复计证据。正式纳排由研究者按预设标准判断。

引文／数值核原来源并标位置；落盘数值及标识同一行标原文位置、工具实测、未核实或自订口径。推算先登记、引用条目并写禁止用途；沿用待确认／未核实／推算／作废标记。网页摘要与子代理关键项由主流程核对。作废规则保留理由与日期，不恢复为现行要求。

## 完成边界

无真实批准保持 `draft`，不得代填 `approved`。完整交付按参考文档生成并核验，先读 `HANDOFF.md`、`delivery.json`：`ready_for_screening` 仅表示 PubMed 候选材料可进入人工筛选，非综述完成或方法认证；`needs_methodology_review` 列研究决策；`needs_execution_repair` 继续修复并保留证据；缺 `delivery.json` 不称完成。

整目录交付，原筛选表保留、另存工作副本。仅草案、局部诊断或单独导出则完成该范围即可。不把试检计数相加为纳入数，不宣称自动满足全部 PRISMA-S；全文、筛选、提取与写作按实际能力处理。
