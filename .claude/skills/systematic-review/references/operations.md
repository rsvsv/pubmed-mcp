# 综述操作导航

本文件只负责定位资料与命令环境。按当前任务读取下表对应章节，不顺序加载全部文档；单独补检、追引或导出不要求先走完整综述流程。

## 文档定位与命令前缀

本文所列文档文件名按以下规则解析，不能按当前工作目录猜路径：

- 全局或便携安装：文档与本文件同处本技能的 `references/`。
- 源码技能：文档位于仓库 `docs/`，从本文件目录解析为 `../../../../docs/`。
- 优先使用本技能随附文档；缺失时只有确认处于源码布局才能回退仓库 docs。两处均缺失就报告缺少文档，不猜开发者机器路径。
- 文档里的其它相对文档引用按该文档所在目录解析；源码文件或测试路径仅作实现定位，安装技能不以原源码目录为运行依赖。

只在要执行 CLI 时读取本技能 `references/installation.json`；`command` 与 `args` 是实际启动前缀，用它们替换文档示例中的 `python pubmed_mcp.py`、`python -I pubmed_mcp.py` 或 `pubmed-review`，保留后续参数。路径作为独立参数传递。记录缺失则核对实际 MCP 启动配置；源码场景可用已核实解释器加 `-I` 与仓库入口绝对路径，不猜安装位置，不为查路径读取无关凭据。

用户资料输出到工作资料目录，路径从当前环境确定。示例名称是本项目自订占位，不是用户研究文件。需要新目录或新文件的操作不得覆盖已有结果；恢复必须使用对应恢复入口。

## 任务到章节

| 触发条件 | 文档与章节 | 完成该阶段须保留的边界 |
|---|---|---|
| 明确问题、拟策略 | `systematic-review-workflow.md`：“先决条件”“拆概念、查词”“组检索式” | 范围和独立已知集来源；草案不等于已批准。 |
| 已知相关文献未找回 | 同文档：“验已知集” | 先排查询失真，再核对字段、限制及标引；未知存在性不是确定漏检。 |
| 改式或复核覆盖 | 同文档：“迭代对比”“机器化核对清单” | 记录改式理由；完整集合变化不能仅看截断预览。 |
| 选择导出格式或取全 | 同文档：“取全导出”；需伴随说明时读 `retrieval-files.md`：“导出文件附说明” | CSV 不含摘要；MEDLINE 保留来源已有字段。切片、计数与缺失警告如实报告，导入兼容性待实际核验。 |
| 按新入库更新 | `retrieval-files.md`：“按入库日期补检”“名单比较与直接导出” | edat 不覆盖所有旧题录后续变化；超窗处理限制按文档执行，保留完整基线。 |
| 保存引用关系或单轮追引 | 同文档：“引用结果留全”“单轮追引用” | 区分参考文献、施引和相似文献；分页不是全量，部分源失败仍须披露；候选不是纳入结果。 |
| 按已有名单导出 | 同文档：“名单比较与直接导出” | 候选文件不能充当完整基线，缺题录不能丢失身份。 |
| 题录导出中断 | 同文档：“题录阶段断点续跑” | 仅恢复已固定名单后的题录阶段，不覆盖搜索取号阶段；保留作业与人工结果。 |
| 写正式交付方案 | `review-delivery.md`：“给助手的输入”“执行入口”；`review-plan.template.json` | 真实批准才填 approved；外部来源的文字记录不等于已执行。 |
| 生成、恢复或核验整份交付 | `review-delivery.md`：“执行入口”“收到什么”“完成状态” | 题录恢复与整份交付恢复不能混用；先读 HANDOFF.md 和 delivery.json，保护原筛选表与修复前快照。 |
| 汇总审计或检查文件绑定 | `audit-report.md`；需要时补读 `retrieval-files.md`：“导出文件附说明” | 核对实际日志与输入完整性；哈希一致不证明检索查全。 |

## 留痕与文件

通过已授权启动方式开启 `PUBMED_AUDIT_DIR`，不擅改全局配置；交付入口自动为任务开启留痕。逐次检查 `audit_status`，字段缺失记状态未知。实际日志可能是 `searches-<pid>-<session>.jsonl` 或兼容旧文件名，不能只找固定旧名。`input_params` 为原始输入，`request_params` 为实际请求；保存调用结果不等于完整网络审计。

子代理只返回结构化数据，主流程核对来源并写文件，随后验证存在、可读及内容完整；失败明确报错。下载数据与脚本分目录，读取下载数据的解释器遵守隔离要求。私人研究名单、日志和安装记录不混入公共分发文件。

文件部署、手工调用和客户端自动发现分别验收。新开会话供宿主重新发现技能；显式读取后能执行不证明自然触发已验证。外部下载、全文阅读和文档制作技能不随本包安装，缺少时说明能力缺口。
