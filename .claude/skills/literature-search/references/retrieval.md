# 检索调整与结果处理

遇到对应问题才读相关章节；不把全部操作串成每次必跑的流水线。正式综述的方案与完成门槛仍由 systematic-review 入口控制。

## 查询与改式

术语不清、跨年代命名变化或覆盖有缺口时查 MeSH：读范围注、入口词、上下位词、历史前身词及引入年份，决定是否展开；同概念已核实结果复用。按 `record_type` 区分描述符、副主题词、药理作用与补充概念。JSON 的 `descriptors` 只含描述符，`other_records` 保留其他类型；`record_order` 是本次展示顺序。字面精确不等于类型相同，也不保证此次取全。无合适描述符时用标题摘要同义词补。

同一概念的同义扩展至少覆盖标题摘要常用词、英美拼写与词形（randomised/randomized、paediatric/pediatric、programme/program；单复数、动名词、截词）。缩写要按摘要里的展开核对：同一缩写可有不同含义（如患者报告结局与被动活动度），缩写共现、首屏排名或题名相似都不足以纳入。保留宽式主题基线，用 `diff` 与实际执行的词形和摘要判断两个叫法是否真指同一概念。

引号内截词是否真的扩展〔未核实〕，尚未有可复核的确定结论；不要把「引号会／不会扩展」写成规则。要判断时做词形确定性对照：对已知单词、其复数／变体和一个完整短语分别取回并核对各自 PMID／标题（不能只看 count），一次只改一个因素；计数差本身不能证明截词生效或失效。

主题基线默认保留核心概念，不加设计词或出版类型门槛。用户限定研究设计时，纳排要求不等于可靠检索过滤器；使用设计筛选须有适配依据并核对遗漏，不能只靠 `randomized` 字词或 RCT 标引。综述导航、已知论文定位和定向补查可收窄，但不替代主题基线或正式综述已批准策略。

先判断下一步缺的是证据内容，还是有效检索集合。已有可信 PMID 与切题题录时先读摘要；只缺字段就补字段，内容已足够则复用。实际执行式有意外扩展，但目标身份可独立核实时，说明偏差并直接读目标，不为修整已完成定位的式子重搜。查询的范围、遗漏、计数、时效或身份疑点影响当前任务时仍须修复；失真集合不能当原式结果，正式综述策略变更仍检查完整增减。读后辨明人群、模型、比较、结局或方法缺口再补查，不能因已找到候选而跳过缺失场景与反向证据。

### 有缺口才触发

| 看到的情况 | 下一步 |
|---|---|
| 细人群的说法不稳定，或关键论文未找到 | 保留核心概念，核对实际措辞；首次治疗、首次活检等细人群词不机械作为必需 AND，必要时移到摘要筛选。没有语法警告仍可能漏检。 |
| 已核实的相关论文没出现在前列 | 需要诊断时用 `check_recall` 区分未命中与已命中未展示。已命中：回已有文件或直接取摘要；存在但未命中：逐概念块用 `count("概念块 AND PMID[uid]")` 核对语法、字段、限制及标引，再补词或放宽。unknown/unavailable 不当漏检。 |
| 问题含不同场景，而已读证据只覆盖其中一类 | 按用户问题中已有的场景（如手术／非手术）定向补查未覆盖分支，或继续分页；不从首屏分布擅自缩小问题。只需简记已有直接证据／待补查，分支未覆盖时不能称完成全面比较。 |
| 前列被综述或不对应的研究占据 | 先读已有切题候选，再按缺口分页或定向补检；收窄式只补充原基线。题名未必含细人群或病程词，优先保留标题摘要范围；用题名定位时，缺少修饰词不构成排除理由。设计词和类型只是线索，`human`、`patient`、`random*` 不能可靠分类；不机械排除综述或动物记录，候选仍须读方法。 |
| 词或缩写命中，但摘要实际评价的是另一对象／干预 | 回摘要方法核对实际纳入对象、给予的干预与测量结局；器械使用、运动／行为干预、不同量表版本不能互换。关键词共现或缩写相同不证明研究的是目标概念。 |
| 要定位量表／问卷／评分工具的原始开发文献 | 用题名关键词＋作者（`author` 字段或 `[au]`）定位，补 development／validation／original 等词，读 `full` 或摘要确认版本。首屏排序、综述引用或高被引不能证明是原始版本；儿童／短版等衍生版不能顶替，未定位就写未定位。 |
| 准备加 AND／NOT 或替换原式 | 保留原集合与修改理由，检查丢失的重要候选，不能以命中减少或锚点找回宣布整体更好。定向补检与原检索互补；正式综述的关键策略变化须检查完整增减。 |

上述是诊断触发条件，不是每次必跑清单。已有独立相关集时复用；日常检索不强制新建金标准，也不把本轮找到的论文倒充独立已知集。`check_recall` 先看 `term_ignored`、`term_degraded` 与各批 `querytranslations`，`retrieved` 只是实取，`found` 是已核实找回；`unknown` 是整批无法判定，按 `checks` 查原因，不算漏检。`missing` 的 `state=present` 只说明记录存在而本次执行式未取回，不指出是哪一项限制造成。要缩小原因，一次只改一项（去掉或放宽日期、字段、某个概念块），其余保持不变并记录改了哪一项；对照结果只支持「在该项下找回」，不能替用户把原因归到其原式、屏幕范围或某个过滤条件。`unavailable`／`unknown` 是存在性未确认，不是漏检。

需要比较策略变化的完整增减时用 `diff`；`preview=True` 可取标题与类型。按共同、新增、未再命中检查相关性，新增数不等于有效研究数。预览不是随机样本或质量排名；未筛完的差集须交代。`max_show` 只限制展示，不减少全集检索；JSON 完整名单不受展示限制。超出窗口时导出后作文件差集，正式抽样另记方法与名单。

## 少重复回传，完整结果可回查

单次小检索用 brief 与 `retmax`，不传 `max_show` 或 `previous_path`；后两者必须配合 `out_path`，不能当普通分页参数。参数名报错时不要猜替法：普通分页去掉 `max_show`／`previous_path`，改用 `retmax`；只有确实要保存请求页快照时才把 `max_show` 与 `out_path` 一起用。多轮改式重复题录较多，或需要保存较大请求页时，使用 `search(out_path=新文件, previous_path=上次快照, max_show=本轮展示上限)`；首次不传 previous_path。返回 JSON，文件保存本次请求页全部标准化题录与查询信息，brief 模式也保存已取得的完整标准化引用。它不是上游原始响应、不含摘要，也不是全部命中名单。

previous_path 只比较此前已展示题录的内容指纹，不改变查询、日期、排序或分页，不额外扫描后续页凑新记录。已展示且未变者不重复展开；已有题录的标准化字段变化时，refreshed_pmids 对应记录重新给出完整引用，避免 brief 隐去更正后的 DOI 等字段。指纹仅覆盖标准化题录，不检测摘要或上游未保存字段的变化。缺题录仍返回 missing_pmids；撤稿等文献类型提示不会随重复题录隐藏。完整 PMID 顺序、比较来源与展示历史在文件中；没有隐式跨任务缓存。

max_show 仅限回传题录数；设为零只存文件，不能记成已阅读。deferred_pmids 是尚未展示的当前页题录，按问题从文件分段读取或继续取摘要，不能只读预览就结束覆盖检查。returned 是本页已取得数，displayed 才是本次展示数；重复全部隐藏不等于零命中。has_more 与 next_retstart 仍按未过滤的原页计算。当前页未看完和后续页未检索是不同缺口，分别记录。

保存/展示不等于人工阅读或筛选。仅在同一任务且此前展示内容仍可回查时复用快照；上下文压缩、任务改变或需要重新审阅时先读原文件，或不带 previous_path。brief 升级 full 会重新展示；题录已展示不能推断摘要已读。文件需保留，哈希仅证明一致性，不证明来源真实性。

批量摘要沿用 `fetch_abstracts(fields="title,abstract,pt,comments,ids", as_json=True, out_path=新文件)` 保存原摘要段落；只读有选择理由或相关性拿不准的记录，必要时回查方法与反方证据。不用模型改写摘要替代原摘要，不默认截断正文；同一 PMID 的题录展示历史不用于跳过摘要。

## 分页与缺失

探索主题常用 `relevance`，追踪新发表用 `pub_date`；新入库另用 `edat` 日期窗口。记录实际看过的范围与选读理由。继续分页可用 `next_retstart`，空值不独立证明取全，仍看 `has_more` 与窗口警告。

有 `missing_pmids` 时按这些编号补取题录或摘要，保留原名单，不重复搜索整页。接受 PMID 的工具可接收官方 PubMed 文章链接。摘要可按需选择 `title,abstract,pt,comments,ids`；检查顶层质量字段，即使已裁剪正文也不能略过 warnings。`missing` 是记录未返回，`no_abstract` 是已请求但返回记录缺摘要，`abstract_requested` 说明是否请求摘要。

汇报时分开写：总命中、本页取得的 PMID（`page_pmid_count`）、本页取到的题录（`page_citation_count`）、缺题录（`missing_pmids`）。保存快照时，本次实际展示看 `displayed`，待展示看 `deferred_pmids`；不能拿 `page_citation_count` 当作展示数。仅展示编号也不等于展示题录，更不等于读过摘要。`search`／`diff` 预览缺题名时保留编号行，按提示用 `fetch_abstracts(pmids=..., fields="title,abstract")` 补取；不能写成「没有命中」，也不能据此推断 NCBI 无此文献。`brief` 无作者与方法；身份核对或方法判断用 `full` 或 `title,abstract`。`missing`（记录未取回）、`no_abstract`（已请求但无）、`abstract_requested=false`（未请求）互相不能代替。

批量正文需要文件时用 `out_path`，读取所需部分。该方式减少回传正文，不能据此宣称上游请求或下载量同步减少。

## 追引与更新

必要时由关键论文查相似文献、参考文献或施引：`links(to="pubmed")`、`links(to="refs")`、`links(to="citedin")` 含义不同。关联为空不证明无引文，也不代表跨库覆盖；部分关联失败须披露。需要保存本次全量关系时用 `out_path`，分页返回不能充当全量。分页按每个种子／每个来源分别切片：记录各源的 `offset`、`limit` 与本页 `page_positions`，不把多种子的页区间混成一个编号。返回顺序是来源关联列表的次序，不是原文参考文献编号、施引年份或质量／被引排名；不能据此称「最新」或「高被引」。大集合先报 `counts.targets`、`targets_returned`、`candidate_pmids` 与未检查／未展示数，再给按源列表或下一页；整页 JSON 转录易错，名单全不等于题名全。

追踪时说明两种日期口径：`pdat`（发表日期）与 `edat`（入库日期）的区间都含首尾，以执行式回显的实际起止为准。同一字段、同一区间的重复条件只是重复，不会变窄；把 `pdat` 与 `edat` 的同日历窗口叠加（同日历边界也不等价），或叠加不等价日期限制，才会取交集把窗口变窄。不要双加，写明实际字段与窗口。跨年在线出版要并列卷期年与 Epub；只知其一或年份对不上时标未核，不按显示年份手删。已有名单先比较差集；没有旧基线只交本窗口候选，不称相对旧检索新增。`removed` 只表示旧集合有、新集合无，不等于数据库删除。补检名单、新增名单和追引候选均不能替换完整基线。

需要文件差集、按名单导出、单轮追引、入库补检或导出续跑时，读取 [综述操作导航](../../systematic-review/references/operations.md) 的“文档定位与命令前缀”，再定位 `retrieval-files.md` 中同名任务章节；这些机械操作不要求升级为完整综述流程。
