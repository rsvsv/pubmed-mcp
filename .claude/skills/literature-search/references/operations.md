# 运行与记录说明

仅在需要保存或核对检索过程、处理审计状态、跨项目安装技能时读取。

## 审计

能通过已授权的服务启动方式开启 `PUBMED_AUDIT_DIR` 时开启，不为日常检索擅改全局配置。逐次检查返回的 `audit_status`：`written`、`disabled`、写入失败或字段缺失分别按实际报告；字段未返回时写审计状态未知，不据此断言后端关闭。保存调用结果不等于有完整网络审计，也不证明检索已穷尽。

## 记录与文件

需要可复用记录时，保存研究用途、数据库、完整检索式、日期限制与检索时点、排序和分页范围、实际查看与选读名单、选择理由、警告、审计状态及未完成项。正文保留关键限制，其余细节放记录文件。用户只要定位论文时，引用及调用记录通常足够，不强制生成报告。

用户的研究材料和真实演练记录放在用户工作资料目录，公开源码仓库只保留通用技能和文档，不混入私人题目、名单或日志。具体目录从当前环境确定，不硬编码开发者机器路径。

下载文献放独立数据目录；脚本与下载数据分开。读取下载数据的解释器遵守当前环境的隔离要求。子代理只返回结构化数据，主流程核对关键来源并负责写文件，随后验证文件存在及内容可读；失败要明确报错。数值与引文来源遵守技能正文和用户规则。

## 可发现性与跨项目使用

源码技能存放于项目 `.claude/skills/literature-search/SKILL.md`；便携安装包将技能和所需文档安装到用户主目录的 `.claude/skills`，可跨项目使用。仅同步 MCP 的 Python 文件不会安装技能。全局安装的 `references/installation.json` 记录服务的实际启动路径；相对文档路径按技能所在目录解析，不按当前工作目录解析。安装后须新开会话供宿主重新发现技能。外部全文下载和文档制作技能不包含在此包中，缺少时如实说明能力缺口。

显式读取技能后执行只能证明流程可执行；让独立执行者按描述选路只能证明描述可理解。只有目标客户端在新会话中实际列出该技能，并在自然任务中选用它，才能报告该客户端的发现与自动触发验证通过。不要把手工指定 skill 的测试说成自动触发测试。
