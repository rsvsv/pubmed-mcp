# 日常文献检索与阅读

从对话提取用途、对象、干预／暴露、结局和限制；只追问会改变下一步的缺项，其余说明暂用范围并开始。演示主题标自订演练。参考文档只读触发章节；本轮已核对且未变化的内容不重读。

## 按需路由

| 任务 | 下一步 |
|---|---|
| 看某篇的参考文献／谁引用了它 | 首调 `links(pmids=种子, to="refs" 或 "citedin", with_titles=True, compact=True, limit=用户要的条数)`；未指定条数时按页。按工具返回顺序列题名，不当作原文编号；只为选读的候选取 `fields="title,abstract"`。 |
| 只问已知论文本身 | PMID／官方文章链接直接 `fetch_abstracts`；题名／DOI 用 `search` 定位。核对身份与所需字段，冲突先解释；完成即交付，不预先计数、查词或读参考。 |
| 按需读 PMC 原文、某章节、图注或表格 | `read_pmc(article_id=PMID或PMCID)` 先列目录，再传目录的 `selector`。只问摘要仍走 `fetch_abstracts`。细节见[阅读](references/reading.md)“PMC 原文选读”。 |
| 概览、选读、比较 | [阅读](references/reading.md)“选读与比较”。 |
| 方法参考／可执行方案 | 阅读文档“实验方法”；可执行参数须核对全文方法、图表和必要补充材料。 |
| 查证论断 | 阅读文档“论断核查”；经验论断查不同方向，方法概念查定义、假设与局限。 |
| 比较改式前后多了哪些论文 | 按下文「放宽后多了哪些」核对每篇的来源；不要求做查新或综述。 |
| 改式、设计筛选、分页、缺题录、追引、更新或重复回传 | [检索](references/retrieval.md)对应章节。 |
| 保存过程、审计、跨项目使用 | [运行与记录](references/operations.md)对应章节。 |
| 判断选题空白、新意、有没有人做过（非正式综述） | 本 skill 下文“判断空白”；要正式证明或穷尽检索才转 systematic-review。 |
| 正式综述、全部找齐、证明无人研究 | 转 [systematic-review](../systematic-review/SKILL.md)；交代单库与未查来源，不能保证无人研究。 |

## 执行

- 主题初检用核心概念，默认不加设计／出版类型门槛，不把细人群、结局全部作必需 AND。方法不是问题本身时，AI、machine learning、deep learning 等方法统称同样不作必需 AND：许多预测模型、影像组学、列线图研究的摘要只写具体方法名。定向定位、综述导航或补检不替代主题基线。术语不清、命名变化或覆盖缺口时查 MeSH 与同义词；同义词扩展含英美拼写、词形与缩写展开，缩写按摘要定义核对。定位原始量表／工具用题名＋作者，不靠排序。
- 阅读摘要默认用 `fetch_abstracts(pmids=..., fields="title,abstract")`：直接读精简文本，不必传 `as_json` 或 `out_path`。按 PMID 区分已读摘要、仅有其他摘要、记录无摘要和未取回记录。提示仅有其他摘要时按需取 `fields="title,other_abstracts"`；未读到正文就不记为已读摘要。需作者单位或 NCBI 原排版时省略 `fields`。
- 已有可信 PMID 和切题题录先读摘要，再按缺口补查；不为修整已完成定位的式子重搜。仍检查遗漏场景与不同方向证据；按理由选读、复用原摘要，不机械取排名前列。
- 问“搜到多少篇”，用 `count` 报检索命中数，不把它说成符合数。问“有多少篇符合条件”，按同一标准逐篇读候选摘要，分别报符合、不符合、待确认和未筛的篇数；没筛完就说“目前确认”，不报成最终总数。遇到否定词、排除标准或对照组描述，引用决定判断的原句。比如问拔牙患者，只纳入非拔牙患者的论文不算；同时比较拔牙与非拔牙患者的论文不能仅因出现“非拔牙”而排除，也不据此自动加 `NOT`。
- 问“这个词在摘要里怎么用”时，给 `search` 传 `context_keyword="要看的词或短语"`，在当前页题录旁看对应原句；只看预览不算筛完摘要，没找到原句也不排除该篇。
- 题录用 `search`；初看 `brief`，完整引用 `full`，仅名单 `ids`。普通分页用 `retmax`；`max_show`／`previous_path` 须配 `out_path`。保存、展示、待看均不等于已读／已筛选。汇报分开命中数、本页 PMID、展示题录与缺题录；缺题名保留编号并按提示补取。日期 `pdat`／`edat` 区间都含首尾；同字段重复不必双加，跨口径叠加取交集。
- 每次核对实际式与警告；影响范围、遗漏、计数、时效或身份的失真须修复，已有候选不能替代有效集合。失败不当零命中；零命中或命中极少须复核：多块式子逐块放宽重计，读多出来的标题摘要；块计数变化只提示漏检位置，原因仍核对字段、标引、语法与限制。检查 `warnings`、`missing`、`no_abstract`、`abstract_requested`：缺题录不等于不存在，未请求摘要不等于无摘要。
- 披露日期、排序与实际查看范围；排名非质量或随机样本，当前页非全集。已知集找回不代表整体查全率，本次命中不倒充独立验证集；日常检索不强制建金标准。

## 判断空白

用于选题、新意或“有没有人做过”；回答要写“空白”“首次”“未见报道”时同样适用。

- 先把空白写成“对象 × 预测因子／暴露 × 结局”；方法标签不构成空白，先确认这个问题有没有任何方法的研究。按核心概念拆块，主题词与标题摘要双轨，补领域缩写（MeSH 入口词常不含）。
- 问「放宽后多了哪些」：沿用字段和日期限制，以 `diff(term_a=原式, term_b=放宽式, preview=True)` 核对当次仅放宽式取到的 PMID。即使原式以前为零，也要当次重比；相对日期须核对实际起止日。逐篇写明「当次仅放宽式取到」或「另行补检／追引，未核对是否新增」，不把数据库更新归因于改式；后者只有核对集合归属后才改标。看返回的 `provenance.comparison`：`not_compared` 说明该调用没比两式；`needs_review` 先报告实取名单差异，并复核执行式、范围和分页。即使核对无误，也只能说「这次新式取到、旧式没取到」，不能只凭名单说是改式造成的。读切题摘要，说明已看哪一页；式子失真先修复，超过比较窗口不宣称取全。
- 已作废〔项目规则修订，2026-11-19〕：「若原式已核实为零，同限制下放宽式实际返回的题录即可证明新增」。理由：历史零命中不能排除后来入库或相对日期窗口移动。
- 对检到的最接近的 3–5 篇（本技能自订的追引起点）做追引：`links(to="pubmed")`、`refs`、`citedin`。少量预览传 `with_titles=True`；已知要读整页候选标题，首次就传 `with_titles=True, compact=True`。文本只截候选详情，不能用显示行数代替关联 PMID 数；超过检查预算按 `offset`、`limit` 分页。要核对是否命中原式，同时传 `term` 和原字段、日期限制。翻专科综述的纳入文献；追到的相关文献记为本轮已知集，用 `check_recall` 测最终式，missing 按[检索](references/retrieval.md)“有缺口才触发”诊断。该集合来自本轮追引，标“非独立已知集”。
- 写明未覆盖：CNKI、万方等中文库，IEEE、MICCAI、AAAI、arXiv 等会议与预印本，在研基金与试验注册。
- 措辞随检索程度分级：只跑过一两个式子写“检索式 X（日期）下未检到”；拆块、放宽、追引、找回做完仍未见写“可能是空白”，附范围与未覆盖来源；已有研究写“已有 n 篇，做到了……、未做……”，点明增量（单中心、无外部验证、只做相关未做预测、预测变量含治疗中信息、只覆盖单一结局等）。不写“真空白”“首次”“尚无任何研究”。
- 附检索记录（式子、时点、命中数、放宽与追引、找回结果、未覆盖来源），按[运行与记录](references/operations.md)保存。用户给出反例时直接承认，指出漏在哪一步，重定空白并说明受影响的结论。

## 证据与交付

按实际范围标明题名初筛、已读摘要、已核对原文选段或已通读全文；核对选段时写明章节或图表位置。题名不证明疗效，摘要不代替完整偏倚评价；临床前不直接外推临床，关联不当因果，不显著不等于无效／等效。多组比较要分清总体检验与逐组结果；总体有差异不等于每组都不同。效应大小、精确度与临床意义分开；研究系列、综述及其纳入研究不重复计证据。

缺摘要、方法不明或全文不可得标 ⚠️【待确认】，不据此排除。撤稿、关注声明、勘误须提示并核对关联；勘误不等于撤稿，未见标记不证明无问题。需要全文则用现有阅读／下载能力，访问或能力不足交代缺口。

关键引文和数值核原来源：摘要标 PMID＋段名，全文标页码／段落／图表。落盘数值及标识同一行注明原文位置、工具实测、未核实或自订口径；推算先登记并引用条目，写明不能证明什么。沿用待确认／未核实／推算／作废标记；撤回保留理由与日期。网页摘要、子代理报告的关键项须由主流程回原来源核对。

先回答问题，再给选读理由、PMID／DOI 链接、分歧与缺口；方法参考给模型适配和全文待核项。正文简述数据库、范围和限制，完整式、时点、选读理由与未完成项留调用记录，需复用或用户要求才出文件。当前问题已有足够证据或不足已说清即可交初步答案；不凑论文数、固定轮数、全量导出或长报告。
