# 检索记账与离线记录表（未发布）

## 它能做什么

开启留痕后，工具把每次检索的输入、实际请求、执行式和结果记到本地。报告命令把日志整理成 Markdown 或 CSV；不联网重查，不把试检次数或命中数累加为纳入数，也不声称满足全部 PRISMA-S 条目。

## 开启记账

在启动 MCP 服务的环境中设置 `PUBMED_AUDIT_DIR` 为日志目录，再重新启动服务。未设置时保持关闭。不要只在另一个终端设置后假定已运行的服务也会收到。

新日志按进程/会话分别写入 `searches-<pid>-<session>.jsonl`，同一进程内写入加锁。旧 `searches.jsonl` 不覆盖，报告兼容读取。查询本身会保存在日志中，分享日志前请核对研究主题是否适合公开。

每次事件有独立 `event_id`、运行标识 `run_id`、带时区的起止时间、工具源码版本、输入参数、逻辑请求列表和结果。`logical_requests` 保存逻辑调用，导出原有 `requests` 保留包含重试的 HTTP 尝试次数；报告兼容旧开发日志中作为数组的 `requests`。嵌套调用共享运行标识但不共享事件标识。结束时间在工具返回或异常之后记录，导出包含发布文件后的时间。

工具及 `--diff-files` 命令的 JSON 返回新增 `audit_status`：`disabled`、`written` 或 `failed`。成功时有日志路径及事件标识；失败时有错误和警告，检索结果仍保留。普通文本在关闭/成功时不变，只在留痕失败时追加警告。

日志写入在线程中执行；正常取消的留痕提交受取消屏蔽保护。滚雪球结果中的 `child_audit_failures` 和警告单独报告子调用写入失败，包括关联查询自身也失败的情形；候选文件和父日志同样保留这些信息。父事件的 `audit_status` 只表示父事件本身。

工具函数内部失败和正常取消也会记账；SDK 在进入函数前拒绝的参数、进程强制终止不保证有记录。不是完整的网络请求流水账，也不保存 API key、email 和原始请求 URL 字段。

## 生成记录表

下面文件名均为示例路径；换成实际日志文件，输出路径必须尚不存在。

```bash
python pubmed_mcp.py --audit-report audit/searches-example.jsonl --out retrieval-report.md
```

多个日志可在同一参数后列出，也可重复 `--audit-report`。旧日志可以与新日志一起输入。

```bash
python pubmed_mcp.py --audit-report audit/searches.jsonl audit/searches-example.jsonl --out retrieval-report.csv
```

损坏行默认使报告生成失败，并给出文件与行号，不写半份正式报告。明确接受部分报告时：

```bash
python pubmed_mcp.py --audit-report audit/searches-example.jsonl --out partial-report.md --skip-invalid
```

部分报告保留 `INVALID_INPUT` 行和原因，命令返回 `input_complete=false`。相同事件标识但内容不同属于冲突，即使开启跳过无效行也仍拒绝。

## 如何读报告

- 每条记录都有来源日志路径、文件哈希和行号；重复的新事件合并后保留多个来源位置。
- 同一物理文件不重复读取；旧记录没有事件标识时保留各行，不用相同查询文本猜测去重。
- 离线差集和纯 PMID 文件导出标为本地文件处理；联网平台按逻辑请求记录填写，缺少依据的旧记录标为待确认。
- 原始式与 NCBI 执行式分别列出；比较查询的两侧也分别保留。`record` 列保留完整记录，便于核对没有单独展开的字段。
- `counts` 是该次事件的数值，来源见同一行的 `evidence`；不能拿来直接填写筛选或纳入数量。
- 旧日志缺少时区、起止时间或参数时写 `⚠️【待确认】`；不会把旧 `ts` 猜成新起始时间。
- 默认只整理日志；显式加 `--verify-files` 时，检查日志中明确记录的导出文件与伴随元数据，并比对日志保存的文件哈希，结果列在 `file_verification`。当前文件对相符但与日志哈希不符时返回 `event_hash_mismatch`；日志没有有效哈希时不能宣称原事件已核验。没有伴随文件就报说明缺失，不猜配；事件哈希仍独立核验。原说明“文件核验仍属后续方案”已作废：本轮已实现该入口〔修订记录：2026-11-14〕。
- 文件核验遇到无法打开的路径（包括包含空字符的路径）时，记录结构化核验错误并继续生成其余记录，不把整份报告中断。空字符在独立文本列中显示为 `\u0000`，`record` 列保留可还原的 JSON 原值。
- CSV 防止以公式符号开头的文本被表格软件执行，会加前置单引号；逐字核对请回到来源日志。Markdown 转义表格分隔符与 HTML。
